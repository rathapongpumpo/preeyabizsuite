# นโยบายความเป็นส่วนตัว — BUZLIKE SYSTEMS

> ข้อมูลที่แบบฟอร์ม BUZLIKE SYSTEMS เก็บ วัตถุประสงค์ ระยะเวลาเก็บ และช่องทางติดต่อเรื่องข้อมูล

URL: https://buzlike.com/privacy



## ข้อมูลที่เก็บ



- เมื่อกดส่งแบบประเมิน เว็บไซต์รับชื่อผู้ติดต่อ โทรศัพท์หรือ LINE ID อีเมลถ้าระบุ ระบบที่สนใจ งบ รูปแบบบริการ และรายละเอียดงานที่กรอก พร้อมเลขอ้างอิงและสถานะการแจ้งเตือน

- ระบบใช้ข้อมูลทางเทคนิคที่จำเป็น เช่น IP ในรูปแฮชสำหรับจำกัดการส่งซ้ำ คุกกี้เซสชันเพื่อความปลอดภัย และบันทึกการทำงานของโฮสต์



## ใช้ข้อมูลเพื่ออะไร



- ใช้รับคำขอ ประเมินขอบเขต ติดต่อกลับเกี่ยวกับงาน และป้องกันการส่งข้อมูลซ้ำหรือใช้งานผิดปกติ ระบบส่งแจ้งเตือนคำขอไปยังอีเมลของ BUZLIKE SYSTEMS ไม่ส่งอีเมลให้ผู้กรอกโดยอัตโนมัติ



## เก็บไว้นานแค่ไหน



- คำขอในระบบหลักมีนโยบายเก็บ 90 วัน และล้างรายการหมดอายุเมื่อ API หรืองานบำรุงรักษาทำงาน

- สำเนากู้คืนเข้ารหัสเก็บย้อนหลัง 14 วัน โดยล้างสำเนาเก่าเมื่อรอบสำรองทำงาน การเปิดหน้าเว็บไม่เรียกงานสำรอง ไม่รับประกันเวลาลบที่แน่นอนหากงานบำรุงรักษายังไม่ทำงาน



## ข้อมูลในเบราว์เซอร์และผู้ให้บริการ



- แบบร่าง แบบจำลองเดโม และจุดกลับหน้าแรกอาจเก็บในพื้นที่เบราว์เซอร์ของคุณ ล้างแบบร่างได้ด้วยปุ่มในแบบประเมิน หรือผ่านการตั้งค่าเบราว์เซอร์

- เว็บไซต์ใช้ผู้ให้บริการโฮสต์และอีเมลเพื่อดำเนินงาน และโหลดแบบอักษรบางส่วนจาก Google Fonts เมื่อเปิด LINE ผลิตภัณฑ์ หรือเดโมภายนอก การใช้งานส่วนนั้นอยู่ภายใต้นโยบายของผู้ให้บริการนั้น
