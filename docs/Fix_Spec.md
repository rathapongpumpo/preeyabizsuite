## Priority 1 (P0): แก้ไขบั๊กเร่งด่วนและปัญหา UX บนหน้าเว็บ

### 1.1 แก้บั๊กฟอนต์ภาษาไทยแสดงผลเป็นกล่องสี่เหลี่ยม (`□□□` Tofu Bug) ในบล็อก Monospace

**ปัญหาที่พบจริง:**

1. **หน้า E-Signature (`/e-signature`):** เมื่อผู้ใช้งานวาดลายเซ็นและกดปุ่ม **"📜 ดูใบรับรอง Audit Certificate"** ข้อความภาษาไทยภายในกล่อง Monospace แสดงผลเป็นสี่เหลี่ยมว่างเปล่า เช่น `Document Title: □□□□□□ (Software Development Agreement)` และ `Signer Name: □□□□ □□□□□ (□□□□ (Managing Director))`

2. **หน้า SmartPOS (`/pos-system-smart`):** เมื่อผู้ใช้งานกดชำระเงิน (QR Code หรือ Cash) แล้วมี Pop-up สลิปใบเสร็จเด้งขึ้นมา ข้อความภาษาไทยในสลิปกลายเป็นสี่เหลี่ยมทั้งหมด เช่น `□□□□: ORD-6028 · □□□: T-01`, `31 □.□. 2569`, `□□□□□□ / Thank you!`

**วิธีแก้ไขสำหรับ Dev:**

1. โหลดฟอนต์ภาษาไทยที่รองรับการแสดงผลร่วมกับ Monospace จาก Google Fonts ในไฟล์ `index.html` หรือ Layout หลัก:

```
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Thai:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;600&family=Sarabun:wght@400;500;600;700&display=swap" rel="stylesheet">

```

2. แก้ไข CSS สำหรับคลาส `font-mono`, `pre`, `code`, คอมโพเนนต์ใบเสร็จ POS และคอมโพเนนต์ Audit Certificate ให้มี Fallback ฟอนต์ภาษาไทยเสมอ:

```
.font-mono,
pre,
code,
.receipt-slip,
.audit-certificate-box {
  font-family: 'JetBrains Mono', 'IBM Plex Sans Thai', 'Sarabun', monospace !important;
}

```

3. หากส่วนใบเสร็จหรือใบรับรองมีการเรนเดอร์ลง `<canvas>` หรือสร้างไฟล์ผ่านไลบรารี PDF (เช่น `jspdf`) ให้เปลี่ยนมาใช้การเรนเดอร์ด้วย HTML/CSS Modal พร้อมสไตล์ `@media print` หรือฝังฟอนต์ `Sarabun-Regular.ttf` (Base64) เข้าไปในตัวสร้าง PDF โดยตรง

### 1.2 แก้ไขปัญหา SPA Direct-URL Routing บน Vercel (`vercel.json`)

**ปัญหาที่พบจริง:** เมื่อลูกค้าคัดลอกลิงก์หน้าเดโมโดยตรง (เช่น `https://preeyabizsuite.vercel.app/warehouse-management`) ไปเปิดในแท็บใหม่ หรือกด Refresh หน้าเว็บในบางเส้นทาง ระบบ Static Hosting ของ Vercel จะไม่พบไฟล์จริงหากไม่ได้ตั้งค่า Rewrite Rule

**วิธีแก้ไขสำหรับ Dev:** สร้างหรืออัปเดตไฟล์ `vercel.json` ที่ Root ของโปรเจกต์ดังนี้:

```
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}

```

### 1.3 แก้ไขแถบ Header บนหน้าแรก (`/`) ไม่ให้มีปุ่มหลอก (Dead UI Elements)

**ปัญหาที่พบจริง:** ปุ่มบน Header ได้แก่ สวิตช์ภาษา (`ไทย / EN`), ช่องค้นหา (`Search...`), ไอคอนกระดิ่งแจ้งเตือน, เมนูโปรไฟล์ `Preeya Systems Engineer` และ Breadcrumb (`My work > Systems Showcase`) กดแล้วไม่มีการทำงานจริง ทำให้ลูกค้าคิดว่าเว็บมีบั๊กตั้งแต่แรกเข้า

**วิธีแก้ไขสำหรับ Dev (ทำครบทุกข้อ):**

1. **ช่องค้นหา (`Search...`):**

   * ผูก State การพิมพ์เข้ากับตัวกรองการ์ดผลงานในส่วนแสดงโปรเจกต์ (`#projects`)

   * เมื่อผู้ใช้พิมพ์คำค้นหา (เช่น `"สต็อก"`, `"POS"`, `"CRM"`, `"ร้านค้า"`) ให้กรองการ์ดโปรเจกต์แบบเรียลไทม์ และเมื่อกดปุ่ม `Enter` ให้เลื่อนหน้าจอ (`scrollIntoView({ behavior: 'smooth' })`) ลงไปยังส่วนแสดงโปรเจกต์ทันที

2. **สวิตช์สลับภาษา (`ไทย / EN`):**

   * **ทางเลือก A (แนะนำหากต้องการขึ้นระบบเร็ว):** ซ่อนปุ่ม `ไทย / EN` ออกจาก Header จนกว่าจะแปลชุดข้อมูลภาษาอังกฤษครบทุกส่วน

   * **ทางเลือก B (หากต้องการเปิดใช้งานทันที):** ผูก Context ภาษา (`lang: 'th' | 'en'`) ให้เปลี่ยนข้อความบนหน้าหลักทั้งหมดจริง ห้ามปล่อยให้ปุ่มเปลี่ยนเป็นสีฟ้าแต่ข้อความยังเป็นภาษาไทยเด็ดขาด

3. **ไอคอนกระดิ่งแจ้งเตือน และ เมนูโปรไฟล์ขวาบน:**

   * **ลบไอคอนกระดิ่งแจ้งเตือนออก** (ไม่จำเป็นสำหรับหน้า Portfolio/Company Website)

   * เปลี่ยนพื้นที่โปรไฟล์ด้านขวาบนให้เป็น **Status Badge + ปุ่ม CTA หลัก**:

     * Badge สถานะ: `🟢 เปิดรับโปรเจกต์ (Available for Q4/2026)`

     * ปุ่ม CTA: `ประเมินราคา / ปรึกษาฟรี` (เมื่อคลิกให้เลื่อนลงไปยังฟอร์มประเมินราคาด้านล่าง)

4. **Breadcrumb (`My work > Systems Showcase`):**

   * บนหน้าแรก (`/`) ให้เปลี่ยนเป็นลิงก์นำทางภายในหน้าที่คลิกได้จริง เช่น `Preeya Systems Studio` > `ผลงานระบบเดโม (6)` > `แพ็กเกจและราคา`

### 1.4 เพิ่ม Loading Skeleton ขณะสลับเข้าหน้าเดโม

**ปัญหาที่พบจริง:** เมื่อคลิกเข้าหน้าเดโมที่มีรูปภาพเยอะ เช่น `/ecommerce-storefront` (`OAI Apparel Storefront`) หน้าจอจะกลายเป็นพื้นที่สีขาวว่างเปล่าใต้ Header นาน 1–2 วินาทีก่อนเนื้อหาจะแสดงผล
